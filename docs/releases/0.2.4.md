# wStreamAudio 0.2.4

Dieses Pre-Release bringt Repository, Dokumentation und Windows-Setup wieder
auf einen konsistenten Stand.

## Änderungen

- Projektangaben und Links auf die Organisation mQorva umgestellt
- README auf den grafischen Windows-Setup-Installer als empfohlenen
  Installationsweg ausgerichtet
- Funktionsumfang und bekannte Einschränkungen mit dem aktuellen Quellcode
  abgeglichen
- Release-Skript von übernommenen Schreibkraft-Bezeichnungen bereinigt
- Versionstags gegen nachträgliches Verschieben auf andere Commits abgesichert
- vorhandene Änderungen an Lautstärkesteuerung, Mini-Fenster und
  Anwendungslifecycle seit 0.2.2 aufgenommen

## Installation

`wStreamAudio-Setup-0.2.4.exe` herunterladen und starten. Das Setup installiert
die Anwendung für den aktuellen Windows-Benutzer und prüft die benötigte .NET
Windows Desktop Runtime 10.x sowie die Windows App Runtime 1.8 x64.

Ein vorhandenes wStreamAudio wird beendet und aktualisiert. Einstellungen und
Logs bleiben erhalten.

## Bekannte Einschränkungen

- Der Installer ist noch nicht digital signiert; Windows SmartScreen kann
  deshalb eine Warnung anzeigen.
- Per-App-Capture ist noch nicht implementiert.
- AirPlay 2 wird nicht unterstützt; der direkte AirPlay-1-Pfad ist
  experimentell.
- DLNA und AirPlay sind nicht samplegenau mit einer LMS-Gruppe synchronisiert.
- Die englische Oberfläche ist noch unvollständig.

Dieses Pre-Release wurde automatisiert gebaut und getestet. Hardwaretests für
alle LMS-, DLNA- und AirPlay-Konstellationen sind damit nicht abgedeckt.
